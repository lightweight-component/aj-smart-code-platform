# SmartCode 平台

SmartCode 是一个低代码平台，由三大组件组成，帮助团队减少重复工作，更高效地构建数据驱动的业务应用。

## 数据服务

AJ DataService 提供统一的 CRUD 服务构建方式，并支持管理基于 SQL 的 API。

[在 GitHub 浏览数据服务源码](https://github.com/lightweight-component/aj-smart-code-platform/tree/main/aj-dataservice)

## 可配置化组件

通过可复用、可配置的组件，快速组合应用功能。

[在 GitHub 浏览可配置化组件源码](https://github.com/lightweight-component/aj-smart-code-platform/tree/main/aj-ui-designer-vue3)

## 可视化表单设计器

基于 Vue 3 和 View UI Plus 可视化设计表单，并将生成的表单 Schema 用于应用中。

[在 GitHub 浏览可视化表单设计器源码](https://github.com/lightweight-component/aj-smart-code-platform/tree/main/aj-form-designer)
